## 🎮 PZ SaveSync v0.3.0 — Distribution & dev experience

13 nouvelles features qui transforment l'app de « outil perso bricolé » en « vrai logiciel ». Focus sur la distribution (CI/CD, auto-update, image sociale, README EN) et la robustesse (logs persistants, recovery, tests pytest).

### 📥 Installation rapide

**À partir de cette release, le `.exe` est buildé automatiquement par GitHub Actions** (plus de build manuel).

Télécharge **`PZSaveSync.exe`** ci-dessous, double-clique.

> ℹ️ Windows SmartScreen affichera un avertissement « éditeur inconnu » au premier lancement (exe non signé). Clique sur **« Informations complémentaires » → « Exécuter quand même »**.

### 🆕 Nouveautés v0.3

#### 🤖 Distribution & developer experience

- **CI/CD GitHub Actions** : tests + py_compile à chaque push (matrice Windows × Python 3.11/3.12/3.13). Build du `.exe` + release auto à chaque tag `v*`. Plus jamais de release manuelle.
- **Auto-update check** : au démarrage, l'app interroge GitHub Releases. Si une nouvelle version existe, bannière bleue cliquable → ouvre la page de download. Bouton "🆕 Vérifier les MAJ" aussi dans Réglages.
- **Image sociale** du repo (1280×640) — generated by `scripts/make_social_image.py`. Preview sympa quand le lien est partagé sur Discord/Twitter/etc.
- **Templates GitHub** : bug report + feature request avec champs structurés. Les rapports moisis sont filtrés.
- **README en anglais** (`README.en.md`) avec switcher de langue en haut.

#### 🪟 UX

- **Drag-and-drop d'un `.zip`** sur la fenêtre déclenche l'import (validation manifest + check intégrité SHA256 + check mods installés + progress bar). Le moment "wow" pour tes potes.
- **Profils multi-groupes** : plusieurs profils (un par groupe d'amis), chacun avec son propre pseudo, dossier partagé, save active et webhook Discord. Sélecteur en haut du header, bouton `＋` pour ajouter. Migration silencieuse depuis la config v0.2.
- **Notifications natives OS** (Toast Windows / `notify-send` Linux / `osascript` macOS) après chaque push/pull/import. Pas besoin d'avoir Discord ouvert.

#### 🛡 Robustesse & sécurité

- **Logger persistant** : `%APPDATA%/PZSaveSync/logs/pzsavesync-YYYY-MM-DD.log` (rétention 14 jours). Bouton "📝 Voir logs" dans Réglages. Stack traces complètes des erreurs → bug reports utiles.
- **Recovery auto** des fichiers `.tmp` orphelins au démarrage (résidus d'opérations crashées).
- **Limites anti zip-bomb** à l'extraction : 5 GB compressé max, 20 GB décompressé max, 50 000 fichiers max.
- **Validation numérique des Workshop IDs** (les non-numériques sont filtrés silencieusement par le parser .ini — anti-injection).

#### 🐧 Cross-platform

- **Support Linux/macOS** : `Path.home() / "Zomboid"` au lieu de `%USERPROFILE%`. Variable d'env `PZ_ZOMBOID_ROOT` pour override.

#### 🧪 Tests

- **45 tests pytest** ajoutés sur 8 nouveaux modules (en plus des 2 tests d'intégration existants). Couverture des cas limites : migration config v0.2→v0.3, hash corruption, prune versions, validation Workshop IDs, parsing versions, etc.

### 🔧 Migration depuis v0.2

- **Aucune action requise.** La config v0.2 (`%APPDATA%\PZSaveSync\config.json` flat) est lue et migrée silencieusement vers le schéma v0.3 avec profils. Ton setup actuel devient le profil "default", tout est préservé.
- Les bundles v1 et v2 restent supportés.

### 🧪 Build & tests

- Stack : Python 3.11+, customtkinter 5.2, tkinterdnd2 0.4
- 45 tests unitaires + 2 tests d'intégration → ✅ tous passent
- Build PyInstaller : ~25 s, `.exe` final ~21 MB
